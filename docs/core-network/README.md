# 🌐 `:core-network` (Overview)

Resilient multiplatform HTTP networking layer powered by Ktor 3.x. It implements remote GitHub API requests with built-in Circuit Breaker, Exponential Backoff Retries, and Rate Limit tracking.

👉 **Detailed Documentation:** See [`core-network/README.md`](../../core-network/README.md) for full architecture, Ktor pipeline, resilience flow, and usage.
