# 📊 `:core-apm` (Overview)

Application Performance Monitoring (APM) and execution telemetry engine for the GitHub Core KMP SDK. It provides high-precision execution timers (`TraceTimer`) and latency tracking that bridge into native APM tools.

👉 **Detailed Documentation:** See [`core-apm/README.md`](../../core-apm/README.md) for full architecture, TraceTimer lifecycle, platform bridging, and usage.
