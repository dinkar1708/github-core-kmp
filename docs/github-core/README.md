# 🚀 `:github-core` (Overview)

Public umbrella facade and distribution module for GitHub Core KMP. It aggregates domain, network, cache, and APM modules into a single entrypoint (`GithubCoreSdk.create()`) for Android, iOS, and Flutter.

👉 **Detailed Documentation:** See [`github-core/README.md`](../../github-core/README.md) for full architecture, assembly graph, distribution targets, and usage.
